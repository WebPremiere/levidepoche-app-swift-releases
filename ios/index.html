Installer sur cet iPhone
  1. Ouvrez cette page dans Safari sur l'iPhone.
  2. Touchez « Installer », puis confirmez : l'icône apparaît sur l'écran d'accueil.
  3. Seuls les iPhone enregistrés par Web Premiere peuvent installer l'app.
  4. Pour une nouvelle version, revenez sur cette page et réinstallez : vos données restent dans iCloud.
